========================================================
はっぴょうメーカー
「先生が作品を集める」ためのGAS設定手順
2026-07-30
========================================================

これを設定すると、児童が「📤せんせいに おくる」を押すだけで、
先生のGoogleドライブに作品が集まります。

  マイドライブ
   └ はっぴょうメーカー_ていしゅつ
       ├ ていしゅつ一覧（スプレッドシート：名前・日時・書いた言葉が一覧に）
       ├ 2026-09-05_1ねん1くみ たろう.json  ← 作品そのもの
       └ ...

先生は同じアプリの「👩‍🏫みんなの さくひん」から、児童の作品を開いて
そのまま発表モードで見せたり、Ctrl+P → PDFに保存で残したりできます。


--------------------------------------------------------
【用意するもの】
--------------------------------------------------------
・先生の学校Googleアカウント
・このフォルダの中の2つのファイル
   - Code.gs
   - （アプリ本体）../index.html

作業時間はだいたい15分です。


--------------------------------------------------------
【手順1】Apps Scriptのプロジェクトを作る
--------------------------------------------------------
1. https://script.google.com を開く（学校アカウントでログイン）
2. 左上「＋ 新しいプロジェクト」
3. 画面上の「無題のプロジェクト」をクリックし、
   名前を「はっぴょうメーカー」に変える


--------------------------------------------------------
【手順2】Code.gs を貼る
--------------------------------------------------------
1. 最初から開いている「コード.gs」の中身を全部消す
   （中をクリック → command+A → delete）
2. このフォルダの Code.gs をテキストエディットで開き、
   command+A → command+C でコピー
3. スクリプトエディタに command+V で貼り付け
4. ★11行目あたりの
      var TEACHER_KEY = 'sensei-himitsu-0000';
   の「sensei-himitsu-0000」を、自分だけのあいことばに書きかえる
   （例：'tahi-2026-sakura'。児童には教えない。日本語より半角英数が安全）
5. 上の💾（保存）を押す


--------------------------------------------------------
【手順3】アプリ本体（index）を貼る
--------------------------------------------------------
1. 左の「ファイル」の＋ →「HTML」を選ぶ
2. ファイル名を  index  にする（.htmlは付けない。「index.html」と表示されればOK）
3. 開いた中身を全部消す（command+A → delete）
4. ★Desktop/はっぴょうメーカー/はっぴょうメーカー_はりつけ用.txt を
   テキストエディットで開き、command+A → command+C でコピー
   （index.html を直接テキストエディットで開くと、コードではなく
     「表示結果」になってしまうことがあるので、必ず .txt を使う）
5. スクリプトエディタに command+V で貼り付け → 💾保存
6. 一番下までスクロールし、</html> で終わっているか確認する
   （途中で切れていたら 3〜5 をやり直す）


--------------------------------------------------------
【手順4】先に1回だけ動かして許可を出す
--------------------------------------------------------
1. 上の関数を選ぶところで「テスト_フォルダを作る」を選び、「実行」
2. 「承認が必要です」と出る → 「権限を確認」
3. 自分のアカウントを選ぶ
4. 「このアプリはGoogleで確認されていません」と出たら
   →「詳細」→「（安全ではないページ）に移動」
   ※自分が作ったスクリプトなので問題ありません
5. 「許可」を押す
6. 実行ログに「できました: https://...」と出ればOK
   マイドライブに「はっぴょうメーカー_ていしゅつ」フォルダができています


--------------------------------------------------------
【手順5】ウェブアプリとして公開（デプロイ）
--------------------------------------------------------
1. 右上「デプロイ」→「新しいデプロイ」
2. 歯車マーク →「ウェブアプリ」を選ぶ
3. 設定：
     説明               : はっぴょうメーカー
     次のユーザーとして実行 : 自分（先生のアドレス）
     アクセスできるユーザー : 「（学校のドメイン）内の全員」
        ↑これが選べない場合は「全員」を選ぶ（下の【注意】参照）
4. 「デプロイ」→ 出てきたURL（https://script.google.com/macros/s/.../exec）
   を コピーして、どこかに控える
   ★これが児童に配るURLです


--------------------------------------------------------
【手順6】動作をたしかめる
--------------------------------------------------------
1. 控えたURLを自分のブラウザで開く → アプリが出る
2. 「📤せんせいに おくる」が出ていることを確認
3. 名前を入れて送ってみる → 「せんせいに おくれたよ!」と出る
4. 「👩‍🏫みんなの さくひん」に自分の送ったものが出る
5. マイドライブの「はっぴょうメーカー_ていしゅつ」に
   ファイルと「ていしゅつ一覧」ができているか確認

★必ず、児童用Chromebook1台で先にURLを開いて確認してください
　（学校のフィルタで script.google.com が使えるかどうかの確認）


--------------------------------------------------------
【手順7】児童への配り方
--------------------------------------------------------
・Google Classroomの資料に手順5のURLを貼る
  （または今のGoogleサイトのページに「はっぴょうメーカー（ていしゅつ用）」
    としてリンクボタンを置く）

・Googleサイトの「埋め込み」に貼ると、また枠の中（iframe）になって
  送信できなくなります。必ず「リンク」で開かせてください。

・先生モードで見るときは、URLのうしろに ?key=あいことば を付けて開きます
    例) https://script.google.com/macros/s/xxxxx/exec?key=tahi-2026-sakura
  （先生自身のアカウントで開けば、あいことば無しでも先生ボタンは出ます）


--------------------------------------------------------
【アプリを直したときの更新方法】
--------------------------------------------------------
1. Desktopの index.html を、スクリプトエディタの index に貼り直す（手順3）
2. 「デプロイ」→「デプロイを管理」→ 鉛筆マーク →
   バージョン「新バージョン」→「デプロイ」
   ※URLは変わりません


--------------------------------------------------------
【注意・こまったとき】
--------------------------------------------------------
■「アクセスできるユーザー」で組織内が選べない／「全員」しか無い
  → 「全員」でも動きます。ただし児童のメールアドレスは記録されません
     （名前は児童が入力したものが残ります）。
     この場合、先生モードは ?key=あいことば を付けて開いてください。

■学校の設定でウェブアプリの公開が禁止されている
  → この方法は使えません。今までのGoogleサイト＋スクリーンショット提出に
     戻すことになります。

■「📤せんせいに おくる」ボタンが出ない
  → 表示に1〜2秒かかります。少し待ってから確認してください。
  → それでも出ないときは、indexを貼り直したあとに
     「デプロイ」→「デプロイを管理」→鉛筆マーク→バージョン「新バージョン」
     →「デプロイ」をしたか確認（貼り直しだけではURLの中身は変わりません）。
  → indexの一番下が </html> で終わっているか確認（貼り付けが切れていた場合）。

■児童が「おくれませんでした」と出る
  → もう1回押す。それでもだめならネットワークかURLの間違いを確認。
     写真が多いと時間がかかります（画面に「おくって います… 1/2」と出ます）。

■同じ子が2回送った
  → 上書きされず、両方が残ります（日時が新しいものが一覧の上に来ます）。

■作品の中身が重い
  → 写真1枚あたり50〜150KB程度です。1クラス30人ぶんでも数十MBなので
     ドライブの容量は問題ありません。

■児童の作品を消したいとき
  → ドライブのフォルダからファイルを消す＋一覧の行を消す（手動）


--------------------------------------------------------
【個人情報について】
--------------------------------------------------------
・作品には児童が入力した名前と、写真（顔が写る場合あり）が含まれます。
・フォルダは先生のマイドライブの中にあり、共有しなければ他の人は見られません。
  「共有」設定を追加しないよう注意してください。
・学年末など、不要になったらフォルダごと削除してください。
